An open source web browser

It runs on chromium but somehow feels like firefox and (will be) highly customisable.
Its main goal is to be minimalistic and sleek.
Though in the future the user will be able to change the looks of the browser according to their style.

2.0.0 will bring a configuration file to add a wide variety of customization.
